# 电脑管理
Status: draft

为 Windows 和 Linux 桌面用户提供原生图形界面，查看并启用或禁用登录自启动、查看系统登记的应用与包、调用其原生卸载器，以及按明确选择清理应用数据和用户缓存。

用户明确要求制作及安装这三项功能。数据清理采用实际路径预览与逐项确认。覆盖 Windows Run 注册表、启动文件夹、登录/启动计划任务、Store 与登记的桌面应用；Linux XDG 桌面自启动、用户 systemd 服务，以及 DEB、RPM、Pacman、Flatpak、Snap 包。保护系统组件、共享数据根目录、个人文档和链接目标。

便携应用、其他用户的数据、远端同步数据及无法可靠归属的残留，不声称自动全部识别；允许在当前用户应用数据根目录内手动指定已核对的数据目录。后台服务不等同于桌面自启动，系统服务不在本次管理范围。

补充用户明确要求：Windows 显示应用、自启动、缓存和进程来源的盘符与实际路径，可按盘筛选。运行管理按可执行文件来源对进程归组，匹配安装路径时展示应用名；无法确认归属时保留真实来源，提供分组资源占用和 PID 详情，可确认结束所选普通进程，受保护系统进程只读。
